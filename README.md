# Contextual Chain (paper release)

This repository is a paper-aligned release prepared from the local workspace.
It contains the final simulator code, experiment scripts, selected summary data, and
supporting documentation needed to reproduce the main results and extension results.

## Directory layout

- `src/` : core simulator code
- `scripts/` : experiment and plotting scripts
- `data/final_summaries/` : lightweight summary CSV files used in the paper
- `docs/` : specification / protocol notes / release notes
- `fig/` : optional pre-generated figures (included only if explicitly requested)

## Reproduction note

This release is intended to expose the final paper-facing configuration clearly.
Large raw result files are intentionally excluded by default. If full raw traces are needed,
archive them separately.
